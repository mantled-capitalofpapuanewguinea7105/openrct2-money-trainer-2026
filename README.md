- Set park money to any value
- Disable loan interest permanently
- Remove park rating scenario requirement
- No bankruptcy game over
- Guest happiness max
- Works on all scenarios and sandboxes

## FAQ

**Does it work in sandbox mode?**  
OpenRCT2 sandbox already has infinite money. This trainer is mainly for scenario campaigns.

**Does it affect saved parks?**  
Yes — save after applying and money persists in the save file.
